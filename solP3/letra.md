# __Proyecto para Ferretería__

## __Contexto__
Rubro ferretería
## __Objetivo__
Generar página web estática
## __Requisitos__
### Contenido
#### Página de inicio (Home) 
- Nombre del negocio y logotipo (puede ser texto estilizado si no diseñan uno) 
-	Slogan o frase que resuma la propuesta de valor 
-	Imagen o banner principal representativo del rubro 
-	Breve descripción del negocio (2-3 líneas)
#### Sobre nosotros / Quiénes somos
- Historia ficticia del negocio (misión, visión, año de fundación) 
- Valores o diferenciales ("qué nos hace únicos") 
#### Productos o servicios 
- Listado con al menos 4 ítems (ej: platillos en restaurante, servicios en veterinaria, categorías en ferretería) 
- Descripción breve de cada uno 
- Precio (opcional) 
- Imagen representativa de cada producto/servicio 
#### Footer 
- Redes sociales (íconos, aunque no funcionen) 
- Aviso legal / derechos reservados 
- Enlaces rápidos de navegación 
#### Funcionalidades
- Navegación entre secciones (menú) 
- Formulario de contacto (sin backend, solo UI) 
- Modo oscuro/claro (toggle)
#### Técnicos
- HTML + CSS + JavaScript
- No usar frameworks
